# Matrix  
# 1. Описание:  
Matrix — это header-only библиотека для простых операций с матрицами на C++.  
Поскольку это HOL, для включения реализации необходимо сначала определить `MATRIX_IMPL` перед подключением библиотеки.  

# 2. Зависимости:  
Библиотека полностью основана на стандартной библиотеке C++ и libc. Дополнительные зависимости отсутствуют.  

# 3. Использование:  
Библиотека используется в исходном виде (.hpp), так как в ней применяются шаблоны.  
Вы можете предварительно скомпилировать её с нужными типами и собрать статическую или динамическую библиотеку самостоятельно,  
поскольку для этого требуется только компилятор C++.  
1. Подключите заголовочный файл  
2. Найдите место, где должна быть реализация, определите `#define MATRIX_IMPL` в этом месте, а затем подключите заголовок  
3. Если вы используете несколько исходных файлов и разные типы в разных файлах,  
вам нужно явно указать компилятору искать реализацию в другом месте, используя `extern`  
во всех файлах, кроме того, который содержит реализацию  

## Формат файла матрицы  
Матрицы хранятся в .txt файле в виде обычного текста.  
Первая строка файла содержит 2 значения, разделённых пробелом: размеры матрицы.  
Далее содержимое матрицы записывается построчно, с разделением столбцов пробелами.  
Пример корректного файла матрицы:  
```
3 3  
1 2 3  
4 5 6  
7 8 9  
```
